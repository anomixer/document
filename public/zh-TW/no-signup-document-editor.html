免費線上文件編輯器——免註冊、不傳伺服器

直接在瀏覽器中編輯 Word（DOCX）、Excel（XLSX）、PowerPoint（PPTX）和 CSV 檔案。無需賬號、無需登入、無需訂閱，檔案也不會傳到任何伺服器。

開啟編輯器 →

大多數"免費"的線上編輯器都會要求你先註冊賬號，然後悄悄把你的文件上傳到它們的伺服器。而這個編輯器兩樣都不做。所有處理都通過 WebAssembly 在你的瀏覽器本地執行，因此你的檔案始終留在裝置上。關掉標籤頁，什麼痕跡都不會留下。

整個編輯器就是被編譯為 WebAssembly、執行在頁面內的 OnlyOffice 引擎。這意味著沒有伺服器在替你幹活，也沒有排隊——開啟檔案即可使用。它支援日常的 Office 格式（DOCX、XLSX、PPTX）以及 CSV，並能把你的成果匯出為 PDF、TXT、HTML 或 CSV。由於它是一個可安裝的 PWA，你可以把它新增到主螢幕，在完全沒有網路的情況下繼續使用。

如何操作

  1. 點選開啟編輯器——沒有任何註冊、登入或賬號步驟。
  2. 從你的裝置中拖入一個 DOCX、XLSX、PPTX 或 CSV 檔案，或新建一個空白文件。
  3. 在瀏覽器中用 OnlyOffice 引擎編輯它——不會上傳。
  4. 把檔案以原格式下載，或匯出為 PDF、TXT、HTML 或 CSV。

為什麼大家選擇它

  • 免註冊、免登入、免訂閱——開啟頁面即可開始編輯。
  • 不傳伺服器——100% 在客戶端執行，文件始終留在你的裝置上。
  • 常見格式全支援——DOCX、XLSX、PPTX 和 CSV，由 OnlyOffice 提供支援。
  • 支援離線——可安裝為 PWA，無網路也能用。
  • 開源——你可以審計程式碼，也可以自行部署。
開源且可自託管。 這個編輯器基於 AGPL-3.0 協議完全開源，所以你不必只聽我們一面之詞——閱讀程式碼即可確認檔案從未被上傳，也可以提交 issue，或執行你自己的副本： github.com/anomixer/document。

常見問題

我需要註冊或建立賬號嗎？

不需要。沒有任何註冊、登入或賬號。開啟編輯器就能立即開始編輯。

我的檔案會被上傳到伺服器嗎？

不會。所有編輯都通過 WebAssembly 在你的瀏覽器本地進行。你的文件永遠不會離開你的裝置。

它真的免費嗎？

是的。它基於 AGPL-3.0 協議免費開源。你也可以從 GitHub 上的原始碼自行部署。

我能離線使用嗎？

可以。它是一個可安裝的 PWA，載入後即可完全離線使用。

我能編輯哪些檔案格式？

DOCX、XLSX、PPTX 和 CSV，由 OnlyOffice 提供支援。你還可以匯出為 PDF、TXT、HTML 或 CSV。

有沒有套路——付費牆或高階版？

沒有。它基於 AGPL-3.0 真正免費且開源，沒有付費牆，也沒有高階版。

我能在手機上用嗎？

可以。它在任何現代移動瀏覽器中執行，因此你無需安裝 App 就能在手機或平板上編輯。
