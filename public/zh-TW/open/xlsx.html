無需 Excel 開啟 XLSX 檔案

收到一個 .xlsx 表格，卻沒裝 Excel——或者不想為 365 付費？直接在瀏覽器裡開啟，公式原樣保留。無需安裝，檔案始終留在本地。

開啟你的 XLSX →

XLSX 是 Microsoft Excel 的格式。這個編輯器用 OnlyOffice 引擎開啟它，因此單元格公式、數字格式、顏色和多個工作表 都能完整保留——它是一個真正的表格，而不是隻讀表格。它通過 WebAssembly 在本地執行，檔案始終留在你的裝置上。

OnlyOffice 表格引擎被編譯為 WebAssembly，執行在你的瀏覽器標籤頁內。你的檔案會被直接從磁碟讀入記憶體——沒有上傳，也沒有伺服器——因此私密資料永遠不會離開你的裝置。由於它是一個即時計算引擎，而不是靜態預覽，公式會隨你的編輯重新計算。它既能讀取現代的 .xlsx 格式，也能讀取較舊的 .xls 和純 .csv，並能匯出回 XLSX 或 CSV。

如何操作

  1. 點選開啟你的 XLSX，在瀏覽器中啟動編輯器。
  2. 從你的裝置中選擇一個 .xlsx 檔案，或將它拖放到頁面上。
  3. 它會用 OnlyOffice 引擎開啟——檢視它，或編輯單元格並看著公式重新計算。
  4. 完成後，把它重新下載為 XLSX 或 CSV。

你可以做什麼

  • 開啟任何 .xlsx（以及 .xls、.csv）檔案，公式完整保留
  • 編輯單元格，再重新下載為 XLSX 或 CSV
  • 無需 Microsoft Excel，也無需 365 訂閱
  • 不傳伺服器——你的表格永遠不會離開你的裝置
  • 可作為可安裝 App 離線使用

它既適合快速地只讀檢視，也適合真正的工作：排序某一列、修正某個數字、增加一行或一個公式，然後以相同格式把檔案交回。當有人給你發來一份預算或資料匯出，而你又不想安裝 Excel、不想為 365 付費、也不想把寧願保密的數字交給某個隨機的網頁轉換器時，這就很方便。

開源且可自託管。 基於 AGPL-3.0 協議——你可以核實檔案確實沒有被上傳，或者執行你自己的副本： github.com/anomixer/document。

常見問題

我能在沒有 Excel 的情況下開啟 XLSX 檔案嗎？

可以。它直接在你的瀏覽器中開啟 XLSX——無需 Excel 或 365 訂閱。

公式和格式會被保留嗎？

會。OnlyOffice 引擎會保留公式、數字格式和樣式。

我的表格會被上傳嗎？

不會。它通過 WebAssembly 在本地執行，永遠不會離開你的裝置。

我能把它匯出為 CSV 嗎？

可以。開啟後重新下載為 XLSX 或 CSV。

它支援舊的 .xls 檔案嗎？

支援。它用同一個引擎開啟 .xlsx、較舊的 .xls 和純 .csv 檔案。

我的公式會重新計算嗎？

會。它是一個真正的表格引擎，因此公式會隨你的編輯重新計算——而不是靜態快照。

支援含多個工作表的工作簿嗎？

支援。含多個標籤頁的工作簿會連同所有工作表一起開啟。
